# ADMS 3351 Midterm Toolkit

This folder contains only the public learning toolkit pages. It does not contain PASS attendance records, student numbers, email lists, or quiz response exports. Quiz practice scores are stored in the learner’s own browser.

## Publish on GitHub Pages

1. Create a new GitHub repository for this site and upload the contents of this folder to its root.
2. In the repository, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**.
3. Push to `main` (or `master`). The included workflow deploys the site; GitHub will show the live address under **Settings → Pages**.

The home page is `index.html`. The quiz, chapters, and Study with AI each have separate HTML pages, with links between them.
